# Panambara Business Solutions: website

Static multi-page site (HTML, CSS, vanilla JS). The shared header, footer and service pages are generated by a small Python script, so there is no framework and no build step on the server.

```
index.html                         home (slider, stats, why us, services, tax band, reels, process)
services/index.html                all services
services/<service>/index.html      one page per service (6)
about-us/  contact-us/             about and contact (form + map)
terms-and-conditions/  privacy-policy/
404.html  sitemap.xml  robots.txt
css/style.css   js/script.js       styles and behaviour
assets/images/                     hero and logo images
tools/build.py                     generates every .html page + sitemap
CONTENT_REVIEW.md                  what changed in the copy and what the owner must confirm
SITE_PROMPT.md                     brief (brand, structure, copy) for reuse
```

## Change the content

Page text lives in `tools/build.py` (service wording, FAQs, legal text, slider copy). After editing:

```bash
python tools/build.py
```

Set the real domain once known so canonical links, the sitemap and social previews use it:

```bash
SITE_URL=https://www.your-domain.lk python tools/build.py
```

## Run locally

```bash
python -m http.server 5500
```

Then open http://localhost:5500.

## Edit in `js/script.js`

- `SOCIAL`: Facebook, YouTube and LinkedIn are set; add a TikTok URL to show its icon.
- `REELS`: YouTube Shorts IDs shown in the Videos section.

## Before going live

- Work through the checklist in `CONTENT_REVIEW.md` (the Terms and Privacy pages in particular should be read by the owner, ideally a legal adviser).
- Rebuild with the live domain (see above).

## Design notes

- Type: Plus Jakarta Sans for headings and body (clear, professional, easy to read on phones).
- Palette: forest green `#06231a`, gold `#c8a24a`, paper `#f6f2e7`.
- Structure follows businessadvisor.lk: top bar, Services dropdown, hero slider, stats strip, why us, services grid, footer columns, a page per service, Terms and Privacy.
- Accessible: skip link, keyboard-operable dropdown, accordion-free FAQs (native `<details>`), carousel with pause control and reduced-motion support.
